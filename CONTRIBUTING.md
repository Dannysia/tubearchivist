# Contributing

This is a personal fork, built for one person's setup. Pull requests are
welcome and will be read, but they are not a priority — expect a slow
reply, and no guarantee a change lands. There is no formal process, no
issue templates and no review SLA. If something here is useful to you,
forking it yourself is a perfectly good option too.

Nothing here is contributed back upstream.

Upstream's contribution guide, which governs the *upstream* project and
not this one, is at
[tubearchivist/tubearchivist/CONTRIBUTING.md](https://github.com/tubearchivist/tubearchivist/blob/master/CONTRIBUTING.md).
Bugs and questions about TubeArchivist proper belong there, or on
upstream's [Discord](https://www.tubearchivist.com/discord). Issues
caused by this fork's changes are not upstream's problem, so please
don't take those to either.

## Coding agents

[AGENTS.md](AGENTS.md) is the authority for coding agents working in this
repo. It grants more than upstream's guide does, deliberately: agents
write code here, including large changes.

The previous contents of this file were upstream's guide verbatim,
including an LLM policy that said the opposite. That contradiction is why
this file is now a pointer rather than a copy.
